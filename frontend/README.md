# Flutter client

Run `flutter pub get`, then `flutter run`.

Android emulator uses `http://10.0.2.2:8000` to reach the host. For a physical phone, use your development machine LAN IP or an HTTPS staging URL.

For production, add secure auth flows, deep links, upload progress, child dashboard, video player, quiz UI, parental controls, localization, crash reporting, accessibility and offline-safe state handling.
